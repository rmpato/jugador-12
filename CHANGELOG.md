# Changelog

All notable changes to the "Boca Juniors 1905" theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [0.2.0] - 2026-08-30

### Changed

- Reworked syntax highlighting from the original two-tone look to a richer, more readable palette while keeping the Azul y Oro identity: navy keywords, brick-red strings, olive italic comments, wine functions, teal types and namespaces, dark-cyan properties, and purple constants.
- Bracket pair colors now cycle navy, wine, and teal.

## [0.1.0] - 2026-08-30

### Added

- Initial release of the Boca Juniors 1905 color theme.
- Gold editor background with dark-ink keywords/strings and pale-gold functions, types, and fields.
- Navy title bar, tab strip, status bar, and panel footer; cream side bar and panels.
- Semantic token colors for accurate Go (gopls) highlighting.
- Boca shield extension icon.
